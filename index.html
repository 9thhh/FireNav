01 / Overview

Better visibility.
Better decisions?

Smoke, poor illumination, and glare can obscure doorways, hazards, and navigation targets. Image restoration offers a natural remedy, but reconstruction fidelity does not necessarily translate into better navigation decisions.

FireNav treats reconstruction features as optional evidence. A lightweight router uses visual information, task context, and prior execution states to decide whether evidence should be admitted and how strongly it should affect native visual tokens. Decision utility calibration learns from the change in action prediction loss with and without candidate evidence.

FireVLN-Bench supplies paired clean and degraded observations, task-preserving references, and matched continuous navigation (CE) and physically simulated robot execution (PE). FireNav improves success and path efficiency while limiting changes to the pretrained navigator.

04 / The FireNav framework

Reconstruction as evidence.
Decisions as supervision.

A frozen native pathway remains the anchor. Auxiliary reconstruction features contribute through a learned, bounded evidence interface.

01 / Read

Retrieve local evidence

Native visual tokens query reconstruction features from the same image through cross-attention. The visual token count and language interface remain unchanged.

02 / Route

Condition on the decision

An image gate controls admission; token weights allocate evidence spatially. Routing uses the task, visual statistics, and available prior execution context.

03 / Calibrate

Learn incremental utility

Offline, compare action prediction losses with and without frozen candidate evidence at the same state. Beneficial and harmful interventions supervise admission.

04 / Preserve

Bound the residual

Constrain feature perturbations, initialize evidence contribution at zero, and regularize clean predictions. Cached features avoid repeated history encoding.

Why route evidence?

Utility calibration matters.

Removing utility calibration lowers SPL by 4.0 points in PE and 4.9 points in CE. Always-on evidence loses 6.0 / 6.9 SPL points.

Clean observation retention

Keep native competence.

Clean SR is 52.8% / 67.1% for FireNav versus 54.1% / 67.5% for native VLN in PE / CE. Retention trades a small degraded-performance gain for better clean behavior.

Navigation update cost

Reuse frozen features.

FireNav operates at 3.19 navigation updates/s, with 389.4 ms P95 latency: 8.4% above native VLN. These rates describe navigation updates, not the locomotion controller.
